## Final Reflection

### 1. What did I build?

I built an automated research report agent that uses CrewAI agents to research,
write, and review a technical report. LangGraph is used to orchestrate the
workflow, while MLflow tracks the execution.

### 2. What was the hardest part?

The hardest part was integrating multiple AI and MLOps components and resolving
environment and dependency issues.

### 3. What would I improve?

I would improve the evaluation system with stronger Ragas metrics, add better
source validation, and deploy the application using a production CI/CD pipeline.
