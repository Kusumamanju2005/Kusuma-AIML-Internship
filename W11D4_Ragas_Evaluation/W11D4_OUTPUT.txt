OPTIMISATION ANALYSIS
---------------------
The lowest valid baseline metric was answer relevancy at 0.4805.
The retrieval configuration was changed from chunk size 300 and top-k 3
to chunk size 200 and top-k 2.

The optimisation experiment completed successfully, but answer relevancy
remained at 0.4805. Context recall decreased from 1.0000 to 0.9000.
Therefore, the tested optimisation did not improve the evaluation scores.

Faithfulness returned NaN in both evaluations, and context precision
returned NaN in the optimised evaluation. These values were recorded
as returned by Ragas and were not fabricated or replaced.

CONCLUSION
----------
The RAG pipeline, 10-question benchmark, Ragas evaluation, and
retrieval optimisation experiment were completed successfully.
The results demonstrate how chunk size and top-k can affect retrieval
quality.
